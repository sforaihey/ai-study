# AI Study

Mobile-first Progressive Web App for short AI Foundations study sessions.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload all files in this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Under "Build and deployment", choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Open the published HTTPS URL on Android Chrome.
7. Chrome menu → **Add to Home screen / Install app**.

The app stores progress locally on the device using localStorage and caches itself for offline use after the first successful load.
